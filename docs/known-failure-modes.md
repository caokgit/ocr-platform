# Known failure modes

One row per failure mode met in this lab: what you see, the cause, the fix, and how to recover. Only
failures that actually happened here, each dated. A row is a living entry: when the failure recurs, the row is
updated (its dates, a better fix). Failures met while running the platform go here too, and the
[runbooks](runbooks/README.md) link to their rows from the step where they happen. Failures met only in access to the client's
systems or in the lab's private notes are left out.
